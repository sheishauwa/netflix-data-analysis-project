# Netflix Data Analysis Project

This project explores the **Netflix Titles Dataset** using Python. It includes data cleaning, exploratory data analysis (EDA), and visualizations to understand trends in Netflix movies and TV shows.

## Dataset
- Source: Kaggle (netflix_titles.csv)
- Contains information such as title, type, release year, duration, country, and genre.

## What Was Done
- Loaded and inspected the dataset
- Cleaned missing and inconsistent values
- Converted movie duration to numeric values
- Analyzed patterns in content type, release year, and genres
- Created visualizations to show insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Netflix added most of its content after 2015.
- Movies are more common than TV shows.
- USA and India produce the highest number of titles.
- The most common genres are Drama and Comedy.
